# Unidad 05 - Entrada y salida

## Descripción

Intercambiar información mediante consola, archivos y formatos de datos.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

## Contenidos

1. System.in, System.out y System.err.
2. Scanner y validación.
3. Lectura y escritura de archivos.
4. Path y Files.
5. CSV, XML y JSON.
6. Introducción a JavaFX.

## Actividad de la unidad

Guardar nombres en un fichero.

## Referencia

https://codelearnacademy.github.io/java/leccion05/

## Conceptos clave

- Diferencia entre entrada y salida.
- Lectura de ficheros de texto.
- Tratamiento de errores de E/S.

## Ejercicios de práctica

1. Guardar nombres en un fichero.
2. Leer un fichero de texto.
3. Contar líneas de un archivo.

   
## Revisión desde GitHub

La entrada y salida permite comunicarse con usuarios y sistemas externos.
