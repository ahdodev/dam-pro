# Unidad 05 - Entrada y salida

## Descripción

Intercambiar información mediante consola, archivos y formatos de datos.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

## Contenidos

1. System.in, System.out y System.err.
2. Scanner y validación.
3. Lectura y escritura de archivos.
4. Path y Files.
5. CSV, XML y JSON.
6. Introducción a JavaFX.

## Actividad de la unidad

Guardar nombres en un fichero.
