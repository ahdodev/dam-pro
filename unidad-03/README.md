# Unidad 03 - Estructuras de control

## Descripción

Tomar decisiones, repetir instrucciones y tratar errores.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

1. if, else y switch.
2. for, while y do-while.
3. break y continue.
4. try-catch y excepciones.
5. Depuración básica.
