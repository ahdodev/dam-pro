# Unidad 02 - Fundamentos de Java

## Descripción

Escribir programas básicos con datos, expresiones y métodos.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

## Contenidos

1. Estructura de una clase y método main.
2. Variables, constantes y tipos primitivos.
3. Operadores y expresiones.
4. Lectura con Scanner.
5. Métodos y parámetros.
6. String y Math.

## Actividad de la unidad

Conversor de Celsius a Fahrenheit.
