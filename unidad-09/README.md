# Unidad 09 - Proyecto final integrador

## Descripción

Diseñar una aplicación de consola que reúna las competencias anteriores.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

## Contenidos

1. Análisis de requisitos.
2. Diseño de clases.
3. Menú y validación de datos.
4. Colecciones y lógica de negocio.
5. Persistencia con SQLite.
6. Pruebas y documentación.

## Actividad de la unidad

Planificar sistema de gestión de alumnos.
