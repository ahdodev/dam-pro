# Unidad 06 - Colecciones y tipos avanzados

## Descripción

Gestionar conjuntos de datos mediante estructuras flexibles.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

## Contenidos

1. Arrays.
2. List y ArrayList.
3. Set y HashSet.
4. Map y HashMap.
5. Genéricos e iteradores.
6. Streams y expresiones regulares.

## Actividad de la unidad

Calcular la media de un array.

- Recorrido con for-each.
- Filtrado mediante streams.
