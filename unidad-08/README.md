# Unidad 08 - Persistencia con SQLite

## Descripción

Almacenar información de forma persistente en una base de datos.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

## Contenidos

1. SQLite y bases de datos relacionales.
2. Conexión JDBC.
3. Creación de tablas.
4. Operaciones CRUD.
5. PreparedStatement.
6. Patrón DAO y transacciones.

## Actividad de la unidad

Crear una tabla de alumnos.

## Referencia

https://codelearnacademy.github.io/java/leccion08/

## Conceptos clave

- Qué significa persistencia.
- Ventaja de consultas parametrizadas.
- Responsabilidad de un DAO.

## Ejercicios de práctica

1. Crear una tabla de alumnos.
2. Insertar y consultar registros.
3. Modificar y borrar registros.

## Revisión desde GitHub

La persistencia conserva los datos más allá de la ejecución del programa.
