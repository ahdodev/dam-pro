# Unidad 01 - Introducción a Java

## Descripción

Introducir Java, la JVM y el proceso de compilación.

## Objetivos

- Comprender los conceptos fundamentales de esta unidad.
- Identificar sus herramientas y aplicaciones en Java.
- Preparar ejemplos y ejercicios para la asignatura.

## Contenidos

1. Historia y características de Java.
2. JDK, JRE y JVM.
3. Bytecode y portabilidad.
4. Instalación de Java.
5. Primer programa Hola Mundo.

## Actividad de la unidad

Comprobar la versión de Java.

## Referencia

https://codelearnacademy.github.io/java/leccion01/

## Conceptos clave

- Diferencia entre JVM y JDK.
- Proceso de compilación con javac.
- Ejecución de un programa.
